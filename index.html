Sobre mí

Cinco años conectando interfaces con la infraestructura que las sostiene.

Empecé maquetando páginas estáticas y terminé diseñando los sistemas que las alimentan. Hoy trabajo de extremo a extremo: desde el primer boceto en Figma hasta el pipeline que despliega el código en producción.

Interfaces

Componentes accesibles y estados de carga cuidados, con React y CSS moderno, pensados para rendimiento real.

APIs y backend

Servicios en Node.js y GraphQL con foco en contratos claros, versionado y tiempos de respuesta bajos.

Nube y despliegue

Infraestructura en AWS, contenedores con Docker y pipelines de CI/CD que llevan cada cambio a producción sin fricción.

Datos

Modelado de bases PostgreSQL, caché con Redis y consultas optimizadas para conjuntos de datos grandes.
